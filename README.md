# Tropical fruit hormone charts

How gibberellin (GA), cytokinin, abscisic acid (ABA), auxin (IAA) and ethylene change through flowering, fruit set and ripening in 13 tropical fruit crops: mango, litchi, longan, durian, mangosteen, rambutan, banana, papaya, pineapple, guava, passion fruit, avocado and citrus.

- `index.html` – the chart page (served by GitHub Pages from the root of `main`)
- `data/*.csv` – the values behind each chart, with verification level and source for every row
- `report.md` – the full research report, including gaps, conflicts and DOI status

Verification levels: **FT** full text read, **ABS** abstract only, **SEC** quoted by a review or guide, **SNIP** search snippet only. Rows marked "Inferred" in `lifecycle_direction.csv` come from the crop's fruit type or general tree physiology, not from measurements in that crop.
